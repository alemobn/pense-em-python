# Pense em Python

Anotações de estudo, algoritmos e resoluções de exercícios práticos baseados no livro **Pense em Python**. O objetivo deste repositório é consolidar os fundamentos da linguagem, lógica de programação e boas práticas de desenvolvimento de software.

## Referência Bibliográfica

* **Título:** Pense em Python: Pense como um cientista da computação
* **Autor:** Allen B. Downey
* **Edição:** 3ª Edição
* **Editora:** Novatec Editora
* **Ano de Publicação:** 2024

## Tecnologias e Ferramentas

* **Linguagem:** Python 3
* **OS Pessoal:** Fedora KDE
* **Estilo e Qualidade:** PEP 8 & Flake8 (Linter)
* **Controle de Versão:** Git (Padrão *Conventional Commits*)

## Estrutura do Repositório

O projeto está estruturado de forma modular por capítulos. Dentro de cada capítulo, o arquivo `anotacoes.py` armazena os conceitos teóricos estruturados em funções executáveis, enquanto o arquivo `exercicios.py` guarda os desafios propostos pelo livro:

```text
.
├── capitulos/
│   ├── c01/
│   │   ├── anotacoes.py
│   │   └── exercicios.py
│   ├── c02/
│   │   ├── anotacoes.py
│   │   └── exercicios.py
│   ├── c03/
│   │   ├── anotacoes.py
│   │   └── exercicios.py
│   └── (demais capítulos estruturados dinamicamente...)
```

## Como Executar os Arquivos

**Para rodar as anotações teóricas:**
```bash
python capitulos/<capitulo>/anotacoes.py
```
**Para rodar as resoluções dos exercícios:**
```bash
python capitulos/<capitulo>/exercicios.py
```

> **Nota de Execução:** Os arquivos usam o bloco `if __name__ == "__main__":` no final. Para testar uma função específica, basta descomentar a linha dela e executar o script.
